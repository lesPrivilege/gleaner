Status vocabulary

Every status is written as words next to the thing it describes. The mark repeats the words and never carries meaning alone. Each mark answers one question: what Gleaner can vouch for.

Solid
Gleaner checked it: the hash matches, or a copy is saved.
Hollow
Known, but not confirmed as the delivered bytes.
Dashed
Not here, but may exist somewhere else.
Triangle
Needs your look. The only state shown in the accent colour.
Cross
Gone. The record stays so you know it existed.

On disk now

Where is the file, and does it still match? Checked on open, on drag, and in the background.

Same as delivery N
Hash matches the latest delivery.
Changed since delivery N
Edited after the last delivery. Nobody has handed you this version.
Unchanged since first seen
Matches what Gleaner first saw, but that was after the delivery.
Not on disk · saved copy available
Gleaner can still hand over the copy it saved.
Not on disk · in git history
A commit has a file at this path. Restore it in the repository; Gleaner doesn’t write there.
Lost
Not on disk, no saved copy, not in git.

Is this what was delivered?

When Gleaner read the bytes, relative to the reply that handed them over.

Seen at delivery
Read by the live watcher right after the reply; the file wasn’t touched in between.
First seen after delivery
Found while reading old sessions. May differ from what was delivered.
Never seen
The file was gone before Gleaner first looked. Only the reply is on record.

Is a copy saved?

Gleaner’s own storage. Your project folders are never written to.

Saved copy
Documents, pages, images: saved by default.
Saved copy (you chose to save it)
A large file you asked Gleaner to save.
Not saved · checked by hash
Large video or build. Fine while the original is unchanged; offers “Save a copy”.
Not saved · version no longer exists
The original changed or vanished; this delivery can’t be handed off.

Hands off cleanly?

Whether the file works once it leaves its folder.

Folder delivered
The agent named a folder; it travels as one unit.
Not self-contained
A single page that loads files beside it. Dragged alone, it breaks.

Who says so

Every claim names its source. Only Gleaner’s own checks become solid marks.

The reply says
Quoted excerpt. “Notarized” in a reply is a claim, shown as text, never as a status.
Gleaner checked
Hash, existence, time of the check.
Git says
Tracked, modified, ignored, or in history at a named commit.
