# Related-work atlas: evidence-bearing neighbors

Review date: 2026-10-17. **F** means full paper text was accessible and the named sections were read; it does not mean every appendix was audited. **D** means official documentation read. **C** means selected implementation source inspected. **R** means repository/README evidence only. **A** means abstract only. None of the reported model results was rerun.

## Memory and experience reuse

**MemGPT: Towards LLMs as Operating Systems** — Packer et al., 2023; **F**, §§2–3. It separates active context from external storage, retains conversation history, and gives the agent paginated retrieval. Its DMR conversation task and nested key-value task already test selective recall and multi-step lookup. It manages an agent runtime, not a retrospective delivered-file catalog. [Paper v2](https://arxiv.org/html/2310.08560v2); [original project/code/data links](https://research.memgpt.ai/).

**Letta AgentFile (.af)** — **D**, legacy V1 documentation, inspected 2026-10-17. The documented portable state includes message history, memory blocks, prompts and tool definitions. Archival passages are explicitly planned, not included. Format compatibility differs from recovering arbitrary logs. “Exact same agent” is documentation wording about serialized state, not proof of identical future execution. [Official AgentFile documentation](https://docs.letta.com/v1-sdk/concepts/agent-file/); [format repository](https://github.com/letta-ai/agent-file).

**A-Mem: Agentic Memory for LLM Agents** — Xu et al., 2025; **F**, §3–4.2. A note contains original interaction content, timestamp, generated keywords/tags/context, embedding and links. New notes can change existing contextual metadata. This is a close antecedent for structured, connected derived metadata; those changes are not an immutable delivered-file version history. Evaluation uses conversational QA, including LoCoMo; it does not test file handoff. [Paper v11](https://arxiv.org/html/2502.12110v11); [evaluation repository](https://github.com/WujiangXu/A-mem); [system repository](https://github.com/agiresearch/A-mem). Repositories checked; not run.

**Zep / Graphiti** — Rasmussen et al., 2025; **F**, §2; **C**, episode/fact structures and retention option. Raw episodic inputs, extracted entities/facts and community summaries are distinct. Facts have temporal validity and links back to episodes. The paper explicitly says source-traversal connections are not directly evaluated in its experiments. Current Graphiti has `store_raw_episode_content=True` by default, configurable off. Thus raw retention and citation traceability have public antecedents; neither implies artifact byte recovery or logical-file identity. [Paper v1](https://arxiv.org/html/2501.13956v1); [pinned retention option](https://github.com/getzep/graphiti/blob/d50741d1bf463cbe3859eb73914cbff1b66839e6/graphiti_core/graphiti.py#L216); [fact source IDs](https://github.com/getzep/graphiti/blob/d50741d1bf463cbe3859eb73914cbff1b66839e6/graphiti_core/edges.py#L267).

**Hindsight is 20/20: Building Agent Memory that Retains, Recalls, and Reflects** — Latimer et al., 2025; **F**, §§3–4 and code-availability section; **R**. It separates world facts, experiences, opinions and synthesized observations, with temporal metadata and token-budgeted retrieval. Evidence/inference separation therefore has prior art. Its “objective” fact category still contains extracted representations; the category itself is not truth verification. Human-authored decisions and immutable deliverable snapshots are different concerns. [Paper v1](https://arxiv.org/html/2512.12818v1); [public implementation/evaluation repository](https://github.com/vectorize-io/hindsight).

**ExpeL: LLM Agents Are Experiential Learners** — Zhao et al., 2023; **F**, overview and introduction. Experiences and extracted insights are reused across tasks without weight updates; successful trajectories supply examples. This invalidates novelty claims for experience reuse or inference-only learning, but does not establish external artifact identity. [Paper v2](https://arxiv.org/html/2308.10144v2); [author repository](https://github.com/LeapLabTHU/ExpeL).

**Agent Workflow Memory (AWM)** — Wang et al., 2024; **F**, §2–3. Workflows are induced from trajectories offline or online. In the online setting, an LM success judgment gates workflow induction. Admission policies therefore already exist, although a success gate differs from a declaration-of-delivery gate. WebArena execution success and Mind2Web step metrics do not establish delivered-byte fidelity. [Paper v1](https://arxiv.org/html/2409.07429v1).

**AriGraph: Learning Knowledge Graph World Models with Episodic Memory for LLM Agents** — Anokhin et al., 2024; **A/R**. Semantic and episodic graph memory supports environment exploration and planning. Relevant through Zep's explicit citation, but not sufficiently inspected here for detailed claims about raw retention, coverage, or version semantics. [Original abstract](https://arxiv.org/abs/2407.04363); [implementation](https://github.com/airi-institute/arigraph).

**MemOS: An Operating System for Memory-Augmented Generation (MAG) in Large Language Models** — Li et al., 2025; **F**, short version §4. MemCube metadata, provenance APIs, lifecycle/version lineage and cross-agent migration are explicit conceptual antecedents. The reviewed version is a proposal; current implementation and performance were not audited. [Short paper v1](https://arxiv.org/html/2505.22101v1).

**Portable Agent Memory: A Protocol for Provenance-Verified Memory Transfer Across Heterogeneous LLM Agents** — Ravindran, 2026; **F**, §§3–5. Overlap: serialization, derivation, integrity and cross-model continuation. However, the claimed SDK was not independently located/verified in this round, and the pilot compares against no memory rather than strong transcript retrieval. Its claims that Graphiti is proprietary and Letta lacks portability should not be repeated: public Graphiti code and AgentFile documentation contradict that blanket framing. Cryptographic integrity does not prove semantic truth. Treat this as relevant prior formulation with limited verification, not decisive efficacy evidence. [Paper v1](https://arxiv.org/html/2605.11032v1).

## Progressive retrieval and agent-facing interfaces

**ReadAgent: A Human-Inspired Reading Agent with Gist Memory of Very Long Contexts** — Lee et al., 2024; **F**, workflow and §3. It associates gist memories with pages, then lets the model choose original passages to read. This directly precedes compact discovery followed by detailed source inspection, including sequential lookup. The principal task is long-document comprehension, not preserving mutable output files. [Paper v3](https://arxiv.org/html/2402.09727v3); [author project](https://read-agent.github.io/).

**A-RAG: Scaling Agentic Retrieval-Augmented Generation via Hierarchical Retrieval Interfaces** — 2026; **F**, §3–4; **R**. Separate keyword search, semantic search and chunk-read tools return IDs/snippets before fuller content. It is especially close to the proposed consumption ladder. Its document QA evaluations and source chunk IDs do not test delivery declarations, missing local history, or artifact version transfer. [Paper v1 as served](https://arxiv.org/html/2602.03442v1); [code/evaluation suite](https://github.com/Ayanami0730/arag). Preserve the cited version: the served page contains a later displayed date, so this review does not infer priority from that display alone.

**AgentRunbook-C / LongMemEval-V2** — Wu et al., 2026; **F**, §3 and §4.2; **R**. Stores past trajectories as files, then uses workflow guidance, manifests and helpers to gather compact evidence. This is the closest academic operational comparator for a retrieval module serving another agent. The study concerns learned environment experience; it does not use final delivery declarations as the artifact inventory boundary. [Paper v1](https://arxiv.org/html/2605.12493v1); [official implementation](https://github.com/xiaowu0162/LongMemEval-V2).

**FileGram** — Liu et al., 2026; **F**, §§3–5; **R**. Synthesized file-system traces include atomic actions, content deltas and final outputs; new-file snapshots and edit diffs make it closer to artifacts than ordinary conversation benchmarks. Its memory and evaluation target personalization/profile reconstruction. This is an important source of task ingredients, not a ready-made declaration-gated handoff evaluation. [Paper v1](https://arxiv.org/html/2604.04901v1); [official repository](https://github.com/Synvo-ai/FileGram).

**MCP, A2A, LangGraph and PROV** — **D**, relevant contract sections. MCP already supports structured tool results, output schemas and resource links; it supplies no inherent completeness or immutable-version guarantee. A2A explicitly represents task artifacts and file references, but is principally a producer-participating exchange protocol. LangGraph checkpoints preserve managed execution state, unlike reconstruction from uncontrolled logs. W3C PROV supplies entities, activities, agents, derivation and revision relations; adopting its vocabulary is interoperability, not a novel provenance model. [MCP 2025-06-18](https://modelcontextprotocol.io/specification/2025-06-18/server/tools); [A2A specification](https://a2a-protocol.org/latest/specification/); [LangGraph persistence](https://docs.langchain.com/oss/python/langgraph/persistence); [PROV-DM](https://www.w3.org/TR/prov-dm/).

Cass, AgentsView and Obelisk receive a pinned comparison in [02-comparison-matrix.md](02-comparison-matrix.md). These are necessary comparisons alongside paper baselines.
