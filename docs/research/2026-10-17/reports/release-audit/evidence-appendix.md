## Additional actionable findings and bounded hardening

**D6 · P2 — “Delivered with” loses the actual linked delivery.** `LibraryModel.swift:108–120` stores sibling artifact IDs only; `DetailView.swift:391–403` selects that artifact and may clear filters but never selects its co-delivered occurrence. Scenario: A1 and B1 arrived together; B was later delivered as B2. From A1, click B under “Delivered with”; B2 opens by default. Impact: evidence-led navigation lands on the wrong event/version, though the new caption names B2. Minimal repair: retain `(artifactID, deliveryID)` per sibling and set both. Evidence is a direct state trace; native acceptance case is supplied. Also, grouping by exact first-record timestamp can split one multi-record Claude reply; preserving a reply/turn key when normalizing is sufficient, with no task object. PR #4's new thread navigation has an explicit delivery selection helper, but its patch does not fix this existing `ReplySection.select` path; do not count it as shipped or a main fix.

**D7 · P2 — Unclosed fenced examples can be admitted.** `MentionExtractor.swift:31,65–83` requires a closing triple fence to mask content. `Example:\n```sh\ncat /tmp/out/report.md\n` therefore leaves an absolute path for the bare-path extractor; `Admission` accepts it. Impact: an instruction/example becomes an apparent delivery and may trigger preservation of unrelated bytes. The exact regex produced no fence match on an ASCII synthetic fixture; the Swift regression is supplied but unrun. [CommonMark fenced-block rules](https://spec.commonmark.org/0.31.2/#fenced-code-blocks) treat an unclosed fence as continuing to the containing block's end. Minimal repair: a small fence scanner that tracks delimiter type/length and EOF, with nested/longer-fence cases. No need to expand the admission rule's scope or resurrect manual Gate 1.

**D8 · P3 — Provider-local session IDs share one primary key.** `Registry.swift:18–22,53–57,100–105` joins every delivery through `sessions.id`; on conflict title/cwd/log change but provider does not. Exact SQL probe: insert Claude `same-id/Alpha`, then Codex `same-id/Beta`; stored session becomes `claude-code/Beta`. Impact: wrong attribution and title-based search if a collision/imported same ID occurs. This is synthetic, not evidence of production UUID collision. Minimal repair: provider-scoped session keys (source scope if importing multiple machines later); preserve delivery occurrence keys separately.

**N4 · P3 — Recovery/action outcomes are weakly surfaced.** `LibraryModel.swift:229–240` and `DetailView.swift:356` ignore `NSWorkspace.open`'s result; `saveCopy` at `319–329` suppresses read/save/database failures; cache Clear similarly suppresses errors. A vanished parent folder, unsupported opener or full storage can leave a button press without an actionable explanation. Minimal repair: route outcome + Retry to the relevant panel, distinguishing cancellation. Test on Mac; no invented toast system or operations dashboard required. Stage failure currently says “Check again,” but ⌘R rereads logs, not the selected artifact (`LibraryModel.swift:132–159`; `DetailView.swift:42–52`). A small selected-file recheck/retry action would make that advice executable.

**Hardening candidates, not newly reproduced failures:** `Locator.sha256:78–85` treats a thrown mid-read error like EOF and returns the digest of a prefix; distinguish EOF from error before using it as verified identity. Type checks followed by opens/copies are vulnerable to a concurrent source replacement by a special file; `Comparison.load` calls the hashing helper without a regular-file check. Concurrent `ContentStore.stage` calls for the same hash/name write/remove the same destination without a unique temporary + atomic publish; test list drag overlapping detail staging on a slow cross-volume file. These deserve focused I/O fault/concurrency tests, not claims that every normal source or receiver fails.

## Probe provenance

`probes/probe.py` executes registry schema/upsert/prune SQL extracted from the audited source, uses actual Git and shell parsing on temporary data, and explicitly labels Python path/regex transcriptions. It is not a substitute for compiling Swift. The external-worktree probe encountered an enclosing `/tmp` repository in this environment: after removal the algorithm chose that unrelated ancestor, instead of Atlas. On a host without that ancestor it falls back to the external cwd name; neither preserves Atlas. The process cache was intentionally absent, corresponding to cold relaunch.

`probes/AuditRegressionTests.swift` contains four expected-failing baseline regressions for Opus to compile/run on macOS: file→folder replacement, missing folder, unclosed fence, malformed reread preservation. It has not been installed in or run against the product checkout. `make_fixtures.py` creates only synthetic inputs for native acceptance and was smoke-tested on Linux; valid PNG encoding was confirmed by `file`. The main repo is clean. All remaining execution limits/access failures are recorded in `process-log.md`.
