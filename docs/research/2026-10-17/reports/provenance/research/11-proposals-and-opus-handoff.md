Separate exact bytes, historical delivery binding, logical identity and approval. Prefer typed rows and evidence manifests until a graph query need appears.

**Best next experiment:** use the provided 20 synthetic checks plus proposed integration fixtures. Add a minimal pure reconstructor for a complete base and a narrow exact-edit form, then a raw Git-blob reader. Require an assumption/coverage report and explicit abstention. This experiment needs no private logs and no provider restore operation. A real-data evaluation would need separately authorized source scope and labels.

**Later:** authored correction persistence, reviewed identity/derivation links, snapshot preservation policy, permission-aware metadata disclosure, and a resolver shaped by a real second domain. Candidate/cataloged/versioned/reviewed remain exploratory labels, not an adopted linear state machine.

**Unsupported:** universal text reconstruction; blanket binary unrecoverability; “Write means wrote”; “exit 0 proves file state”; “same hash means same logical object”; “nearby timestamp proves delivery version”; universal checkpoint existence/retention; universal prospective-instrumentation claims; generic provenance novelty.

**Provider finding to carry forward:** current public Claude documentation specifies checkpoint and asset locations/limits; Gemini documents opt-in shadow-Git checkpoints. Codex source was pinned at `ce0323f2f2d3b25e82806cd555237da3db4e1897`: rollout persistence has mode-dependent filtering/truncation, and legacy ghost-snapshot handling does not establish a current recovery guarantee. None of these capabilities was tested against a private account.

**Potential distinctive contribution, still a hypothesis:** a source-preserving artifact retrieval experience that clearly separates user-facing delivery declarations, observed/reconstructed representations, uncertain identity/derivative relations, and authored governance, with conservative fallback when evidence is missing. Establish differentiation through comparison and user evaluation; do not claim a new provenance theory or first retrospective system.
