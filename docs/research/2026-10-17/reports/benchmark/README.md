Read [claims and experiment design](deliverables/01-claims-and-design.md), [scoring](deliverables/03-scoring-and-statistics.md), then the [26 task specifications](deliverables/04-tasks-shared-information.md). The proposed comparison holds model capability and available evidence equal, includes competent session/section search, and charges preparation cost. Its separate captured-state condition asks which facts become available when approval records or historical bytes actually exist. These remain unadopted research proposals.

Executed evidence is limited to [ten fictional information/lifecycle checks](deliverables/09-synthetic-results.md), with [code](synthetic/probe.py), [results](synthetic/run-001/results.json), [configuration](synthetic/run-001/config.json) and [fixture manifests](synthetic/run-001/fixture-manifests.json). Zero model trials or retrieval-strategy comparisons were run. The assembler checked hashes, Python syntax, JSON and document structure without rerunning the probe.
