# Source atlas navigation

The reports link primary sources and label their reading depth. This index routes by question; it does not imply that the assembler independently reran source research or competitor evaluations.

| Question | Atlas | Representative primary precedents |
|---|---|---|
| How should an agent discover and read bounded content? | [Interface/retrieval atlas](../reports/cli-schema/02-interface-retrieval-atlas.md), [interaction examples](../reports/cli-schema/07-interaction-examples.md) | Structured developer CLIs, MCP tools/resources/templates, indexed document navigation |
| How should identity, representations and evolving fields be distinguished? | [Identity/schema atlas](../reports/cli-schema/03-identity-schema-atlas.md) | Git, content-addressed artifacts, catalog/distribution models, schema matching/evolution |
| Which systems already support agent history retrieval and handoff? | [Related-work atlas](../reports/prior-art-novelty/01-related-work-atlas.md), [comparison matrix](../reports/prior-art-novelty/02-comparison-matrix.md) | Cass, AgentsView, Obelisk, MemGPT, Graphiti, ReadAgent, AgentRunbook-C |
| What can retained records prove about past artifacts? | [Reconstruction papers](../reports/provenance/research/02-paper-atlas.md), [linkage/semantics](../reports/provenance/research/02b-linkage-and-semantics-atlas.md) | Git2PROV, YesWorkflow, observed/possible provenance, record linkage |
| How do mature systems address preservation and evidence access? | [Standards/implementation atlas](../reports/provenance/research/03-standards-and-implementation-atlas.md), [provider evidence](../reports/provenance/research/04-provider-evidence.md) | W3C PROV, DCAT, Web Annotation, PREMIS, OpenLineage, pinned Codex persistence code |
| How can benefit be evaluated without confounding new evidence with retrieval? | [Benchmark source/dataset atlas](../reports/benchmark/deliverables/07-primary-research-and-dataset-atlas.md), [existing evaluations](../reports/prior-art-novelty/03-existing-evaluations.md) | Information retrieval relevance/citation evaluation, memory benchmarks and public trajectory cards |

Full papers, third-party source snapshots, raw search responses and dataset shards are excluded. Public access is not treated as a redistribution license. Source pins, observed license context and access failures remain in each report's evidence/process records. No new dependency is adopted by inclusion in an atlas.
