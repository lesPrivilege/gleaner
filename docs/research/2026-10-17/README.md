# Gleaner: review and research reference

Five independent streams, assembled for local Opus on 17 October 2026. The question is whether agents can reliably find the intended project delivery, select its exact version, inspect only the needed section, trace evidence and hand the same artifact onward.

Start with the release review when deciding readiness. For future work, read the consumption synthesis, then the cross-stream handoff. The source atlases and complete evidence remain one level deeper.

[Opus handoff and open choices](decisions/opus-handoff.md) compares structured command-line interface (CLI) expansion, a thin Model Context Protocol (MCP) adapter and a shared query/read core. These are options, not an adopted product contract. The strongest research question concerns correct artifact/version selection under incomplete evidence; progressive retrieval and retrospective provenance themselves already have substantial prior art.
